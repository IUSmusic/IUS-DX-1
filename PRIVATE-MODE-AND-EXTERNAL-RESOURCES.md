# IUS DX-1 Private Mode and External Resources

IUS DX-1 may include LAB level controls for runtime status, soundbank verification, imports, optional model routes, adapters and private development resources.

Optional model routes are not the core product message. The core product is a rhythm first drum production system for source mix generation, groove capture, full track arrangement, MIDI editing, groove shaping, drum controls, FX, routing and soundbank management.

Private or development resources should not be redistributed unless their rights are fully cleared and the material is approved for public release.
